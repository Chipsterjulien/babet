Historical design notes for babet.find
======================================

The original discussion below guided the current implementation of depth, type,
name/iname and path filtering. Babet 2.6.0 adds bounded glob filters
(`glob`, `iglob`, `path_glob`, and `path_iglob`) and migrates the historical
regex fields to locally built static RE2 while preserving their matching
semantics. Babet 2.21.0 adds the remaining filesystem-boundary control as
`xdev = true`, with the same useful traversal contract as `find -xdev`: the
mount point remains visible, while its descendants are pruned. The boundary is
`st_dev` (so Btrfs subvolumes and same-filesystem bind mounts follow the same
semantics as `find -xdev`), and Babet 2.21.1 closes the remaining live-tree disappearance race for all
find traversals. The implementation now uses an explicit stack of directory
iterators, advances the parent before opening a child, and skips only `ENOENT`
when an entry or active directory frame disappears. All other traversal errors
remain fatal, so a partial result is never mistaken for a complete search.
